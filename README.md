# Sticky Posts Limit

A WordPress plugin that limits the number of sticky posts automatically.


## Features
- Set sticky post limit
- Auto-remove older sticky posts
- Lightweight and fast

## Installation

**From WordPress (Recommended)**  
Go to Plugins → Add New, search for *Sticky Posts Limit*, install and activate.  
Or download from WordPress.org: https://wordpress.org/plugins/sticky-posts-limit/

**Manual Upload**  
Upload the ZIP via Plugins → Add New → Upload Plugin, then activate.
